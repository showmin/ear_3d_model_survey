## 三條貫穿全文的硬性規範

**0. 用語規範。** 耳部部位與醫學名詞一律**中文在前、英文於括號內**，例如 耳屏（tragus）、耳甲腔（cavum conchae）、迷走神經耳支（auricular branch of vagus nerve, ABVN）。首次出現標全稱與縮寫，其後可只用中文。（需求方 2026-08-21 指示）


**1. 每一條都必須可判定。** 帶數字門檻。「壁厚應足夠」不收，「壁厚 ≥ X mm」才收。

**2. 每個數值標來源等級。** 未標記的數字不得進入交付版。

| 標記 | 意義 |
|---|---|
| 【實測】 | 我們或委託方實際量到的 |
| 【文獻】 | 可核驗的公開來源，附出處 |
| 【慣例】 | 業界工程慣例，無單一權威來源 |
| 【假設】／【待核】 | 尚無依據，待驗證後填入 |
| 【推論】 | 本團隊的推論，非來源直述 |

理由：指引錯了，後面**所有**設計都會照著錯下去。寧可交一份多處標【待核】的誠實文件，也不要一份數字填滿、看起來專業但其實是編的。

## 目前最重要的三個未決事項

1. ⛔ **服務哪個使用情境？** A 臥睡／B 坐睡／兩者。**這一題影響最大**——形態選型的優劣排序在兩情境間會**翻轉**（掛耳式在 A 是最差、在 B 是強候選；頭帶眼罩式相反）。見 [Part 1.0](cn/01-use-scenario.md) 與 [Part 4.2.3](cn/04-max-design-envelope.md)。
2. **側睡凸出高度上限** — 無公開來源，只能實測。**僅情境 A 適用**；若只做情境 B，此缺口消失。見 [Part 4](cn/04-max-design-envelope.md)。
3. **機型 S／M／L 三檔的目的** — 功能取捨（驅動器／電池）或產品線區隔？決定機型-L 該不該逼近包絡上限。（「適配不同耳朵」已由定義排除，那是配件尺寸的職責。）

## 已確認的永久邊界（非待補項）

需求方於 2026-08-21 確認無其他可用資料。以下限制**不會被後續資料填補**，各有替代做法，詳見 [Part 2.0.2](cn/02-anthropometric-basis.md)：

| 限制 | 替代做法 |
|---|---|
| 無法依性別分檔 | 改用「涵蓋 P5–P95 全距」策略；耳甲區域改用 Part 2.3 文獻值 |
| 年齡偏低或未知 | 上緣留餘裕 ＋ **佩戴測試必須納入年長受試者** |
| 無耳後與乳突區資料 | **掛耳式標為高風險路徑**，必須實體樣機驗證後才能定案 |
| 無耳道深部尺寸 | 由耳印模或實體試戴決定 |
| 族群未確認 | Part 2.2 標「未確認」；Part 2.3 為中國樣本可作亞洲參考，僅限耳甲 |

## 已知能力邊界（寫進正文，不藏附註）

- **佩戴壓力無法模擬驗證**：缺超彈性與接觸求解器，且耳部軟組織材料參數無可核驗來源。最終須實體試戴。
- **聲學高頻無法模擬**：無波動 FEM/BEM 求解器，僅集中參數模型，有頻率上限。見 Part 5。
