## このリストは誰のためのものか

**利用者＝このガイドラインを使って設計する人。** 3D モデルを作成した後、本リストと項目ごとに照合して自己点検する。

**これは要求元に記入して返してもらうアンケートではない。** リストは成果物の一部であり、成果物を書くための前提条件ではない。

リストには性質の異なる 2 種類の項目がある。分けて読むこと：

| 区分 | 性質 | 誰がいつ扱うか |
|---|---|---|
| **A. シーン前提** | **プロジェクト範囲の決定** | **要求元が着手前に確定する**。以降は変更しない。3–4 問のみ |
| **B–H** | **モデル点検項目** | **設計者がモデル完成後に**自分のモデルを項目ごとに照合する |

表示の説明：
- 「⛔」＝**却下項目**：不適合なら製品として成立しない。減点ではない
- 「⏳」＝**現時点で数値しきい値がない**。本ガイドラインは方法のみを示し、実測で補う必要がある

**すべての項目は判定可能である**——はい／いいえで答えられる。答えられなければその項目の情報が不足しているということであり、それ自体が結論である。

## A. シーン前提（Part 1）

> **本節は要求元が着手前に決定する。** 設計者の点検項目ではない。以下の数問のみであり、B–H 節がモデル点検にあたる。

### A-0 まずこの問いに答える——以下のどの節が該当するかを決める

- [ ] ⛔ **どのシーンを対象とするか？ A 一晩中の臥位睡眠／B 座位睡眠／両方。**
  B はさらに分かれる：**B1 オフィス仮眠**／**B2 短距離通勤**（降車駅を見る必要あり）／**B3 長距離交通**。
  **両方を対象とする場合、両制約の和集合を満たす必要があり、横向き寝が依然として拘束条件となる。**

### A-1 全域項目——シーンを問わず一律に適用

- [ ] 「**利用者は睡眠中に無意識であり**、自分で調整も不快への反応もできない」という前提を受け入れるか？
- [ ] ⛔ **装着試験に高齢被験者を含めているか？** 現有の寸法データは年齢が低いか不明であり、耳の寸法は生涯にわたり増大する。**この欠落は試験でしか埋められず、数値では埋められない**（Part 2.0.2 参照）
- [ ] 寸法設計は上限側に余裕を持たせ、高齢利用者をカバーしているか？
- [ ] 耳珠（tragus）を主たる保持支点にすることを避けているか？ 同部位は**最も圧迫に敏感な領域であり（Part 3）、かつ顎の動きで変形する（Part 1A）**
- [ ] ⛔ **耳型採取または装着検証は「開口」状態を含んでいるか？** 下顎の弛緩が外耳道を変形させる（被験者 30 名全員で発生）。閉口のみでは必要なフィット許容幅を系統的に過小評価する。
  **仰向け寝と座位睡眠の双方で生じる**——仰臥では下顎が落ち、座位では頭部前傾時に口がわずかに開く（[Part 1A.2、1A.4](01a-posture-analysis.md) 参照）

### A-2 シーン A（一晩中の臥位睡眠）専用

- [ ] 製品は**一晩中連続装着**か、それとも入眠後に外すか？ 後者なら圧力と耐久の要求を大幅に緩和できる
- [ ] **右側臥位**を重点的に検証したか？（高齢利用者は右側臥位を明確に好み、右耳の累積圧迫が高い）

### A-3 シーン B（座位睡眠）専用

- [ ] ⛔ **居眠り時に頭部が前傾・側方へ倒れても、保持され脱落しないか？**（保持はシーン B の支配的制約であり、横向き寝の突出高さに代わる位置を占める）
- [ ] U 字型ネックピローが耳後部と頭部側面に接触する影響を考慮したか？（イヤーフック型で特に関係する）
- [ ] 遮音は静かな寝室ではなく交通騒音（低周波が主体）を対象に設計したか？（**B2／B3**）
- [ ] 着脱と収納は容易か？（使用が頻繁であり 1 日 1 回ではない）
- [ ] ⛔ **状況安全に必要な環境音の把握を確保しているか？**（**B2 が最も重要**——降車駅を見る必要があり乗り過ごしてはならない。完全な密閉遮断はこのシーンでは利点ではなく欠点）
- [ ] 公共の場での外観は受容可能か？（**B1 が最も厳しい**——同僚がいる。B3 が最も緩い）
- [ ] 日中の環境光に対処しているか？（**座位睡眠に固有**——夜間の問題は「光をなくす」ことだが、日中は逆に「光が多すぎる」。Part 1A.4.1 参照）

<a id="sec-9-b"></a>
## B. 敏感領域と配置禁止領域（Part 3）

- [ ] ⛔ **荷重を受ける保持構造は耳珠（tragus）を避けているか？**（耳甲介 6 点のうち実測で最も敏感）
- [ ] ⛔ **カナル部は外耳道（EAM）の後下壁を避けているか？**（Arnold 咳嗽反射の誘発領域。約 2–4% の利用者に咳嗽が生じる）
- [ ] 保持力は主に耳輪（helix）／対耳輪（antihelix）が担っているか？
- [ ] 耳甲介舟（cymba conchae）への持続的な集中圧迫を避けているか？
- [ ] 文書やマーケティングで自律神経（autonomic）への効果を主張していないか？（taVNS の文献は電気刺激であり、受動的圧迫へ外挿できない）

<a id="sec-9-c"></a>
## C. 設計可能領域（Part 4）

- [ ] ⛔⏳ **横向き寝の境界を満たすか？ 判定基準は形態ごとに異なる。Part 4.2.1 参照。** 現時点で**数値がなく**、実測後に記入する必要がある
  （**シーン A のみ該当。シーン B は枕による圧迫がないため本項は成立しない**——これは座位睡眠が解消する最大の制約である）
  - カナル型 → 耳介外縁に対する突出高さ
  - イヤーフック型 → 頭部側面最外縁の厚さ ＋ 乳様突起部（mastoid）への圧力 ＋ 耳介が折れ曲がらないこと ＋ フックが剛体レバーでないこと
  - フラットオーバーイヤー型／ヘッドバンド／骨伝導 → Part 4.2.1 の該当行を参照
- [ ] **突出高さは代理指標にすぎず**、本当の物理量は枕から耳へ伝わる接触圧であることを理解しているか？（低くても硬く尖った突起は、高くても幅広く丸く弾性のあるものより痛いことがある）
- [ ] イヤーフック型専用：耳後部本体は十分に薄くしたか？ フックはレバー増幅を避けるため低剛性としたか？
- [ ] ⛔ **イヤーフック型を選ぶ場合：実機による横向き寝検証を計画に入れたか？** 本ガイドラインはイヤーフック型について**実測に基づく根拠を一切持たない**（耳後部のスキャンデータがない）。Part 4.2.2 はすべて推論であり、**そのまま確定してはならない**
- [ ] 幾何は解剖学的エンベロープ内にあるか？（**機種 S／M／L は同一の耳に装着できる 3 種類の本体サイズであり、耳のサイズ区分ではない**。3 つの機種は同一のエンベロープを共有し、それぞれが耳型の全範囲を収容しなければならない）
- [ ] 3 種類の「サイズ」を区別しているか？ **機種 S／M／L**（本体の大きさ）／**イヤーチップ XS〜L**（アクセサリ）／**耳型区分 I／II／III**（利用者の耳の大きさ）。Part 0.4b 参照
- [ ] 寸法の基準に**アジアの成人**データを用いているか？（集団差が顕著であり、欧米のデータと混用してはならない）
- [ ] 解剖学的エンベロープは男女別か？（耳の寸法は分ける。圧迫しきい値は分けない）
- [ ] **角度**を伴う保持構造で、左右共用を前提としていないか？（角度系の寸法は左右非対称）
- [ ] 2 つの境界が衝突する場合、横向き寝の境界を優先しているか？

<a id="sec-9-d"></a>
## D. 音響（Part 5）

- [ ] 前気室（V_front）／後気室（V_back）の容積は定義済みか。各機種のシェル容積に応じて比例配分しているか？
- [ ] ⛔ **漏れ経路は実際の幾何形状を示しているか**（狭隙は幅×高さ×長さ、円孔は半径×深さ）。**等価面積のみになっていないか？**（幾何が質量支配か粘性抵抗支配かを決める。誤ると静かに誤り、エラーにならない）
- [ ] **漏れ経路の幾何に測定時の顎の状態を明記しているか？** 密閉型カナルは開口状態を基準とするか両方を併記する——静止測定は漏れを過小評価し遮音を過大評価する（Part 1A の仰向け寝での外耳道変形を参照）
- [ ] シミュレーションが信頼できる周波数上限を理解しているか？（カナル型 L≈8–12mm → ~3.5–5.4 kHz。オーバーイヤー型 L≈20–30mm → ~1.4–2.1 kHz）
- [ ] 上限を超える音響性能について、シミュレーションではなく実測で検証する計画があるか？
- [ ] 完全密閉を採る場合、オクルージョン効果（occlusion effect）に対処しているか？

<a id="sec-9-e"></a>
## E. 構造と材料（Part 6）

- [ ] 肉厚は選定した造形プロセスの下限を満たすか？（FDM ≥1.0–1.2mm、荷重部材 ≥2.0mm。SLA 0.4–0.6mm）
- [ ] オーバーハング角はサポート不要の上限内か？（FDM 45°。SLA 30° かつ張り出し ≤2mm）
- [ ] ⛔ **耳シェル内腔のサポートは取り出せるか？**（完全に閉じた行き止まり穴を避けるか、可溶性サポート材を用いる）
- [ ] 軟質接触面は**複合方式**（硬質シェルを造形＋軟質チップを外部調達）か、**完全造形**か？ 完全造形の場合、接触面硬度の下限が約 Shore A 43–50（睡眠用イヤーチップに一般的な 10–20A よりはるかに硬い）となることを受け入れるか？
- [ ] Shore A と Shore 00 を混用していないか？（低反発フォーム／軟質ゲルは Shore 00、一般的なシリコーンは Shore A。数値は相互比較できない）
- [ ] 耐久試験方法は材料種別に対応しているか？（弾性材は ASTM D5963。硬質シェル塗膜は ASTM D4060。**両者を混用してはならない**）
- [ ] ISO 105-E04 を誤用していないか？（これは繊維製品の染色堅牢度であり、シリコーン／プラスチックの劣化には適用できない）

<a id="sec-9-f"></a>
## F. 装着圧と快適性（Part 7）

- [ ] ⏳ **本項目はシミュレーション検証できず**、実機装着試験が必須であることを理解しているか？
- [ ] 短時間の PDT をそのまま一晩装着の圧力上限としていないか？（長時間の耐容値は必然的に低いが、どれだけ低いかのデータはない）
- [ ] 接触は点接触ではなく面接触か？
- [ ] 接触面は丸められ、鋭利なエッジや硬い稜がないか？
- [ ] Part 7.4 の 4 項目の実機試験を計画しているか？

**3 つの低コスト簡易スクリーニング（Part 7.4.1）——機器不要。これを済ませてから本測定へ：**

- [ ] **頭振り試験**：素早く首を左右に振り、上下に頷いたとき、イヤホンは微動だにしないか？ ずれる＝サイズが小さすぎるか角度が合っていない
- [ ] ⛔ **咀嚼／開口試験**：口を開閉し話す真似をしたとき、耳珠（tragus）に鋭い痛みが出ないか？ **出ればサイズが大きすぎる。直ちに 1 段小さくする——これは慣れの問題ではなく構造が合っていない**
- [ ] ⛔ **15 分ルール**：装着したまま 15 分歩く。**持続する圧迫感はすべて誤ったサイズの兆候であり、慣れるべきものではない**
- [ ] **装着角度**は耳介の曲線に沿っているか？ 角度がずれれば、サイズが正しくても痛む

<a id="sec-9-g"></a>
## G. CMF（Part 8）

- [ ] ⛔ **スリープモードで充電ケース／ドックのインジケータは既定で全消灯か？**（充電ケースはベッドサイドで目を正面から向いており、イヤホン本体の光よりはるかに重要）
- [ ] 点灯が必要な場合、集団平均 24.6 lux ではなく**最も感受性の高い個人の 6 lux** を基準としているか？
- [ ] 輝度は照度計を用い、**実使用時の距離と角度で目の位置に到達する値**を測定して検証したか。LED のスペックシートを引用していないか？
- [ ] スリープモードで点滅／ブリージング効果を禁止しているか？
- [ ] 左右耳と表裏を**触覚で識別**できるか？（暗所で装着するため視覚に頼れない）
- [ ] 表面処理は想定する洗浄方法に耐えるか？（毎日の IPA 拭き取りはマット面を光沢化させ、設計を破綻させる）

## 現時点で通過できない項目（正直な一覧）

以下の項目は本ガイドラインの現段階で**数値しきい値がなく**、誰も照合できない。これは既知の欠落であり、見落としではない：

| 項目 | 何が欠けているか | どう補うか |
|---|---|---|
| ⛔⏳ 横向き寝の突出高さ上限 | 本件で最も重要な数値。メーカーはいずれも非公開 | 競合品のノギス実測＋枕の沈み込み実測 |
| アジア成人の**性別別の耳介外形**エンベロープ | 耳介外形は実測があるが集団が未確認かつ性別未分。耳甲介は性別別の文献があるが耳甲介に限る。両者の交差が欠けている | 人口統計を伴う 3D スキャン、または系統的レビューが引用する原著研究の追跡 |
| PDT の絶対値 | 相対順位のみ（耳珠が最も敏感） | Applied Ergonomics の全文を取得する |
| 長時間の静的圧迫の耐容値 | データが一切ない | 実機装着試験 |
| 硬度—圧力の対応関係 | 定性的な方向のみ | 硬度違いのテストピースで界面圧を実測 |
| パッシブ遮音の dB 目標 | 検証可能なデータがない | 実測 |
| 睡眠用イヤーチップ 10–20A の硬度 | 独立した第 2 の出典がない | 市販品を実測、またはメーカー仕様を取得 |
