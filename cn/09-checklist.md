## 這份清單是給誰用的

**使用者＝拿這份指引做設計的人。** 他做出 3D 模型後，逐項對照本清單自我檢查。

**這不是一份要交回給需求方回答的問卷。** 清單是交付物的一部分，不是撰寫交付物的前置條件。

清單分兩種性質的條目，請分開看：

| 區段 | 性質 | 誰在什麼時候處理 |
|---|---|---|
| **A. 場景前提** | **專案範圍決策** | **需求方在專案開工前拍板**，之後不再更動。只有 3–4 題 |
| **B–H** | **模型檢查項** | **設計者在模型完成後**逐項核對自己的模型 |

標記說明：
- 「⛔」＝**否決項**：不合格則產品不可用，不是扣分
- 「⏳」＝**目前尚無數值門檻**，本指引只能給方法，需實測補齊
- 「**⚑**」＝**閘門條目**：見下方

**每一項都是可判定的**——答得出是／否；答不出就表示該項資訊不足，那本身就是結論。

<a id="sec-9-rules"></a>
### ⚑ 閘門條目——未通過時，其轄下條目「不可判定」

某些條目是**判定其他條目的前提**，例如「架構是否已宣告為密封式或洩壓式」。未宣告就往下勾，會勾到錯的那一組——**而且全部會勾成功**。

> ⛔ **清單最危險的失效不是勾不過，是勾錯組卻全過。**

**規則**：閘門條目未通過時，其轄下條目一律標記為**「不可判定」**。
**不得留白**（會被讀成「還沒做」），**也不得勾選**（那是假通過）。

### 否定式條目必須配一條肯定式條目

**凡條目形式為「未做 X」或「A 未被牴觸」者，必須配一條「該做的事是否已做」或「A 是否已被指定」。**

> ⛔ **否定式條目單獨存在時，什麼都沒做的設計會全部通過。**

這兩種寫法是同一個失效模式的兩面——**檢查缺席而不檢查存在，漏掉的永遠是「什麼都沒做」那一種**。它不是違規狀態而是預設狀態，**而預設狀態不會觸發任何檢查。**

| 只有這一條會空過 | 必須配上 |
|---|---|
| 「整機擺放方向未牴觸聲學孔軸」 | 「孔軸是否已指定平行列印 Z 軸」——否則孔軸從沒被指定過的設計會安靜通過 |
| 「未使用亥姆霍茲 f₀ 反解決定導管尺寸」（密封式） | 「導管尺寸的決定依據是否已記載」——否則隨手畫一個尺寸也照樣勾過，他確實沒用亥姆霍茲 |
| 「未套用 f₀ 印小補償」（密封式） | 「印小量對 V_front 容積帳的影響是否已納入」——「沒做補償」不等於「處理正確」 |
| 「接觸區不存在 R < X 的稜線」 | 「接觸區圓角是否已指定」 |

> **前置關係寫在條目上，不靠章節排版順序保證。** 之後有人重排章節時，排版慣例會斷，明寫的前置不會。

<a id="sec-9-a"></a>
## A. 場景前提（Part 1）

> **本段由需求方在開工前決定**，不是設計者的檢查項。全部只有下列數題，其餘 B–H 段才是模型檢查。

### A-0 先答這題——它決定下面哪些段落適用

- [ ] ⛔ **服務哪個情境？A 整夜臥睡／B 坐睡／兩者皆是。**
  B 再分：**B1 辦公室午睡**／**B2 短程通勤**（須看站）／**B3 長途交通**。
  **若兩者皆是，須滿足兩組約束的聯集，側睡仍為綁定條件。**

### A-1 全域條目——不分情境，一律適用

- [ ] 是否接受「**使用者睡眠中無意識**、無法自行調整或反應不適」這個前提？
- [ ] ⛔ **佩戴測試是否納入年長受試者？** 現有尺寸資料年齡偏低或未知，而耳部尺寸終生增長。**此缺口只能靠測試補，不能靠數字補**（見 Part 2.0.2）
- [ ] 尺寸設計是否於上緣留有餘裕，以涵蓋年長使用者？
- [ ] 是否避免以耳屏（tragus）為主要固位支點？該處**既是壓力最敏感區（Part 3），又隨下顎移動而變形（Part 1A）**
- [ ] ⛔ **耳印模或佩戴驗證是否涵蓋「口張開」狀態？** 下顎鬆弛使耳道變形（30 名受試者全數出現），只取口閉合會系統性低估所需貼合寬容度。
  **正睡與坐睡皆會發生**——仰躺時下顎下墜，坐睡頭前傾時口部微張（見 [Part 1A.2、1A.4](01a-posture-analysis.md)）

### A-2 情境 A（整夜臥睡）專用

- [ ] 你的產品是**整夜連續佩戴**，還是入睡後取下？後者可大幅放寬壓力與耐久要求
- [ ] 是否已針對**右側臥**加重驗證？（老年使用者明顯偏好右側臥，右耳累積壓迫較高）

### A-3 情境 B（坐睡）專用

- [ ] ⛔ **打瞌睡時頭部前傾、側倒，裝置是否仍能固位不脫落？**（固位是情境 B 的主導約束，取代側睡凸出高度的地位）
- [ ] 是否考慮 U 型頸枕接觸耳後與頭側的影響？（對掛耳式尤其相關）
- [ ] 是否針對交通噪音（低頻為主）而非安靜臥室設計隔音？（**B2／B3**）
- [ ] 穿脫與收納是否便利？（使用頻繁，非一日一次）
- [ ] ⛔ **是否保留情境安全所需的環境感知？**（**B2 最關鍵**——須看站不可坐過站。完全密封隔絕在此情境是缺點而非優點）
- [ ] 外觀在公開場合是否可接受？（**B1 最嚴**——同事在場；B3 最寬）
- [ ] 是否處理白天環境光？（**坐睡特有**——夜間問題是「不要有光」，白天反過來是「光太多」，見 Part 1A.4.1）

<a id="sec-9-b"></a>
## B. 敏感區與禁置區（Part 3）

- [ ] ⛔ **承壓固位結構是否避開耳屏（tragus）？**（耳甲六點中實測最敏感）
- [ ] ⛔ **入耳部是否避開外耳道（EAM）後下壁？**（Arnold 咳嗽反射誘發區，約 2–4% 使用者會咳嗽）
- [ ] 固位力是否主要由耳輪（helix）／對耳輪（antihelix）承擔？
- [ ] 是否避免對耳甲艇（cymba conchae）持續集中壓迫？
- [ ] 是否未在文件或行銷中宣稱任何自律神經（autonomic）效果？（taVNS 文獻為電刺激，不可外推至被動壓迫）

<a id="sec-9-c"></a>
## C. 可設計區域（Part 4）

- [ ] ⛔⏳ **側睡邊界是否通過？判準依形態族而異，見 Part 4.2.1。** 目前**無數值**，須實測後填入
  （**僅情境 A 適用。情境 B 無枕頭壓迫，此條不成立**——這是坐睡情境解掉的最大約束）
  - 入耳式 → 相對耳廓外緣的凸出高度
  - 掛耳式 → 頭側最外緣厚度 ＋ 乳突區（mastoid）壓力 ＋ 耳廓未被折彎 ＋ 耳掛非剛性槓桿
  - 扁平耳罩／頭帶／骨傳導 → 見 Part 4.2.1 對應列
- [ ] 是否理解**凸出高度只是代理指標**，真正的物理量是枕頭傳進耳朵的接觸壓力？（矮而硬尖的凸點可能比高而寬圓有彈性者更痛）
- [ ] 掛耳式專用：耳後主體是否已極薄化？耳掛是否為低剛性以避免槓桿放大？
- [ ] ⛔ **若選掛耳式：是否已排定實體樣機側睡驗證？** 本指引對掛耳式**無任何實測依據**（無耳後掃描資料），Part 4.2.2 全為推論，**不得逕行定案**
- [ ] 幾何是否在解剖包絡內？（**機型 S／M／L 是同一顆耳朵可戴的三種機體大小，不是人耳分檔**；三個機型共用同一組包絡，且各自都須容納整個耳型範圍）
- [ ] 是否分清三種「尺寸」？**機型 S／M／L**（機體多大）／**耳塞 XS～L**（配件）／**耳型分段 I／II／III**（使用者耳朵多大）。見 Part 0.4b
- [ ] 尺寸基準是否採用**亞洲成人**資料？（族群差異顯著，不可混用歐美資料）
- [ ] 解剖包絡是否分男／女？（耳部尺寸要分；壓力門檻不分）
- [ ] 涉及**角度**的固位結構，是否未假設左右通用？（角度類尺寸左右不對稱）
- [ ] 兩邊界衝突時，是否以側睡邊界優先？

<a id="sec-9-d"></a>
## D. 聲學（Part 5）

- [ ] 前腔（V_front）／後腔（V_back）體積是否已定義，並依各機型殼體容積比例分配？
- [ ] ⛔ **漏氣路徑是否提供實際幾何**（窄縫給寬×高×長，圓孔給半徑×深），**而非只給等效面積？**（幾何決定質量主導或黏性阻力主導，給錯會錯得很安靜、不報錯）
- [ ] **漏氣幾何是否註明量測時的下顎狀態？** 密封式入耳應以口張開為準或兩組都給——靜止量測會低估漏氣、高估隔音（見 Part 1A 正睡耳道變形）
- [ ] 是否理解模擬可信頻率上限？（入耳 L≈8–12mm → ~3.5–5.4 kHz；耳罩 L≈20–30mm → ~1.4–2.1 kHz）
- [ ] 上限以上的聲學表現，是否已規劃以實測驗證而非模擬？
- [ ] 若採全密封，是否已處理遮蔽效應（occlusion effect）？

<a id="sec-9-e"></a>
## E. 結構與材料（Part 6）

- [ ] 壁厚是否符合所選列印製程下限？（FDM ≥1.0–1.2mm，承力件 ≥2.0mm；SLA 0.4–0.6mm）
- [ ] 懸空角度是否在免支撐上限內？（FDM 45°；SLA 30° 且懸空 ≤2mm）
- [ ] ⛔ **耳殼內腔的支撐是否取得出來？**（避免全封閉盲孔，或改用可溶性支撐材）
- [ ] 軟質接觸面採**複合方案**（列印硬殼＋外購軟塞）還是**純列印**？若純列印，是否接受接觸面硬度下限約 Shore A 43–50（遠高於睡眠耳塞常見的 10–20A）？
- [ ] Shore A 與 Shore 00 是否未混用？（記憶棉／軟凝膠用 Shore 00，一般矽膠用 Shore A，數值不可互比）
- [ ] 耐久測試方法是否對應材料類型？（彈性材 ASTM D5963；硬殼塗層 ASTM D4060；**兩者不可混用**）
- [ ] 是否未誤用 ISO 105-E04？（那是紡織品染色牢度，不適用於矽膠／塑膠劣化）

<a id="sec-9-f"></a>
## F. 佩戴壓力與舒適（Part 7）

- [ ] ⏳ 是否理解**本項無法模擬驗證**，必須實體試戴？
- [ ] 是否未將短時間 PDT 直接當作整夜佩戴的壓力上限？（長時間可承受值必然更低，但低多少無數據）
- [ ] 接觸是否為面接觸而非點接觸？
- [ ] 接觸面是否已圓角化，無銳邊與硬稜？
- [ ] 是否已規劃 Part 7.4 的四項實體測試？

**三個低成本快篩測試（Part 7.4.1）——不需儀器，做完再進正式量測：**

- [ ] **甩頭測試**：快速左右搖頭、上下點頭，耳機是否紋絲不動？有位移＝尺寸偏小或角度不對
- [ ] ⛔ **咀嚼／張口測試**：張合嘴巴、模擬說話時，耳屏（tragus）是否出現尖銳痛感？**有就是尺寸過大，立即降一號——這不是適應期問題，是結構不合**
- [ ] ⛔ **15 分鐘法則**：戴著走動 15 分鐘。**任何持續性壓迫感都是錯誤尺寸的訊號，不是需要適應**
- [ ] **佩戴角度**是否順著耳廓曲線？角度歪了，尺寸再對也會痛

<a id="sec-9-g"></a>
## G. CMF（Part 8）

- [ ] ⛔ **睡眠模式下，充電盒／底座指示燈是否預設全滅？**（充電盒在床頭櫃正對眼睛，比耳機本體的燈重要得多）
- [ ] 若必須亮，是否以**最敏感個體 6 lux** 為基準，而非群體平均 24.6 lux？
- [ ] 亮度是否以照度計在**實際使用距離與角度、量測到達眼睛位置的值**驗證，而非引用 LED 規格書？
- [ ] 睡眠模式下是否禁用閃爍／呼吸效果？
- [ ] 左右耳與正反面是否可**觸覺辨識**？（暗室中配戴，無法依賴視覺）
- [ ] 表面處理是否耐受預定的清潔方式？（每日 IPA 擦拭會使霧面變光亮，等於設計失效）

- [ ] 引用的論文是否**實際開啟讀過**，而非從搜尋摘要推斷？
- [ ] 引用的標準是否查到編號與適用範圍，而非憑印象寫？

## 目前無法通過的項目（誠實清單）

以下項目在本指引現階段**沒有數值門檻**，任何人都無法核對。這是已知缺口，不是疏漏：

| 項目 | 缺什麼 | 怎麼補 |
|---|---|---|
| ⛔⏳ 側睡凸出高度上限 | 全案最關鍵數字，廠商均不公開 | 競品卡尺實測＋枕頭壓陷實測 |
| 亞洲成人**分性別之整耳外廓**包絡 | 整耳外廓已有實測但族群未確認且未分性別；耳甲已有分性別文獻但僅限耳甲。缺兩者交集 | 含人口統計的 3D 掃描，或追系統性回顧所引原始研究 |
| PDT 絕對數值 | 只有相對排序（耳屏最敏感） | 取得 Applied Ergonomics 全文 |
| 長時間靜態受壓可承受值 | 無任何數據 | 實體試戴測試 |
| 硬度—壓力對應關係 | 只有定性方向 | 不同硬度試片實測界面壓力 |
| 被動隔音 dB 目標 | 無可核驗數據 | 實測 |
| 睡眠耳塞 10–20A 硬度 | 無獨立第二來源 | 實測市售產品，或取得原廠規格 |
