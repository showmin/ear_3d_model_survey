## 全文を貫く 3 つの必須規範

**0. 用語規範。** 耳の部位名と医学用語は必ず**日本語を先に、英語を括弧内に**記す。例：耳珠（tragus）、耳甲介腔（cavum conchae）、迷走神経耳介枝（auricular branch of vagus nerve, ABVN）。初出時に正式名称と略称を示し、以降は日本語のみでよい。（原則は発注者 2026-08-21 指示。中文版は「中国語＋英語」）

**1. すべての条項は判定可能でなければならない。** 数値しきい値を伴うこと。「肉厚は十分であること」は不可、「肉厚 ≥ X mm」なら可。

**2. すべての数値に証拠等級を付す。** 未表示の数値は納品版に入れてはならない。

| 表示 | 意味 |
|---|---|
| 【実測】 | 当方または委託先が実際に測定したもの |
| 【文献】 | 検証可能な公開情報。出典を付す |
| 【慣例】 | 業界の工学的慣例。単一の権威ある出典なし |
| 【仮定】／【要確認】 | 根拠未取得。検証後に記入 |
| 【推論】 | 当チームの推論であり、出典の直接の記述ではない |

理由：ガイドラインが誤っていれば、以降の**すべての**設計がその誤りに従う。【要確認】が多数残る正直な文書のほうが、数値で埋め尽くされ専門的に見えるが実は捏造された文書より望ましい。

## 現時点で最も重要な 3 つの未決事項

1. ⛔ **どの使用シーンを対象とするか？** A 臥位／B 座位／両方。**この 1 問の影響が最も大きい**——形態選定の優劣順位が 2 つのシーン間で**反転する**（イヤーフック型は A で最悪、B では有力候補。ヘッドバンド／アイマスク型はその逆）。[Part 1.0](jp/01-use-scenario.md)、[Part 4.2.3](jp/04-max-design-envelope.md) 参照。
2. **横向き寝での突出高さ上限** — 公開情報がなく、実測するほかない。**シーン A のみ該当**。B のみであればこの欠落は消える。[Part 4](jp/04-max-design-envelope.md) 参照。
3. **機種 S／M／L の 3 段階の目的** — 機能上のトレードオフ（ドライバ／バッテリ）か、製品ラインの differentiation か？ 機種-L をエンベロープ上限まで攻めるべきかが決まる。（「異なる耳サイズへの適合」は定義上除外済み。それはアクセサリ側の役割。）

## 確定した恒久的境界（未補充項目ではない）

発注者が 2026-08-21 に他の利用可能データがないことを確認済み。以下の制約は**後続データで埋まることはない**。それぞれ代替手段がある（詳細は [Part 2.0.2](jp/02-anthropometric-basis.md)）：

| 制約 | 代替手段 |
|---|---|
| 性別で分けられない | 「P5–P95 の全域をカバーする」方針に変更。耳甲介領域は Part 2.3 の文献値を使用 |
| 年齢が低いか不明 | 上限側に余裕を持たせる ＋ **装着試験に高齢被験者を必ず含める** |
| 耳後部・乳様突起部のデータなし | **イヤーフック型を高リスク経路として明示**。実機検証を経ずに確定してはならない |
| 外耳道深部の寸法なし | 耳型（イヤーインプレッション）または実機装着試験で決定 |
| 集団が未確認 | Part 2.2 は「未確認」と表示。Part 2.3 は中国人サンプルでありアジアの参考になるが耳甲介領域に限る |

## 既知の能力限界（本文に明記し、注記に隠さない）

- **装着圧はシミュレーションで検証できない**：超弾性ソルバと接触ソルバがなく、耳の軟組織の材料パラメータにも検証可能な出典がない。最終的には実機装着試験が必須。
- **音響の高周波はシミュレーションできない**：波動 FEM/BEM ソルバがなく集中定数モデルのみ。周波数上限がある。Part 5 参照。
